# Civilization VI Governor Portrait Skill

A reusable prompt-generation skill for creating expressive, stylized Governor portraits inspired by Civilization VI's strategy-game character presentation.

## Two input modes

### Historical character

Input:

> 岳飞

The skill automatically interprets the historical identity and creates a historically grounded Governor portrait prompt.

### Free-form description

Input:

> 一个中国男性，魁梧、武将、正义

The skill converts the description into a coherent character design, including body type, face, expression, costume, accessories, palette, pose, and rendering.

## Visual characteristics

- expressive, slightly exaggerated 3D face
- strong character identity
- chest-up / waist-up framing
- polished AAA strategy-game rendering
- PBR materials
- soft directional studio lighting
- pure white background
- characteristic soft fade at the lower edge
- no text, logo, UI, or scene

## Output

Each request produces:

1. Character Interpretation
2. Main Prompt
3. Negative Prompt

## Style reference

The skill uses Civilization VI as a high-level visual reference for strategy-game character presentation. It does not reproduce proprietary character models or assets.
